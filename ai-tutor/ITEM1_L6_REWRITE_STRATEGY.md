### Rewrite Pattern Applied

**BEFORE (Definition-based):**
```
Question: "Which is present habitual?"
Options: ["खाना", "खा रहा है", "खाता है", "खाया है"]
Answer: "खाता है"
```

**AFTER (Usage-based / Context-focused):**
```
Question: "Fill in the blank: 'हर दिन मैं स्कूल ___'"
Options: ["जाता हूँ", "जा रहा हूँ", "गया हूँ", "जाऊँगा"]
Answer: "जाता हूँ" (habitual - every day)
Explanation: "Every day = repeated action = present habitual = जाता हूँ"
```

### L6-C03-L05: Case Markers Introduction ⚠️⚠️⚠️
**Current Issue**: Likely describes 8-case Sanskrit system (WRONG for modern Hindi)
**Priority**: CRITICAL - Was identified as major fix needed
**Complete Rewrite Needed**:

**OLD (WRONG)**:
```
Explains nominative, accusative, instrumental, dative, ablative, genitive, locative, vocative
(8 cases - Sanskrit, not modern Hindi)
```

**NEW (CORRECT)**:
```
Modern Hindi uses: Nominative (कर्ता) + Oblique (indirect)
Not 8 cases like Sanskrit

Nominative (Direct): मैं, तू, यह, वह
Oblique (Indirect): मुझे (को), तुम्हें, इस (को), उस (को)

MCQs:
1. "Fill blank: 'मैं ___ खाना पसंद है'"
   Options: किताब | किताब को | किताबें | किताबों को
   Answer: किताब को (direct object)

2. "Which case-marked form shows who 'likes'?"
   Options: मुझे | मेरा | मै | में
   Answer: मुझे (experiencer, not agent)
```

---

### L6-C03-L06 to L11: Demonstrate Oblique Marking
**Key Concept**: Case markers appear in 3 scenarios:
1. **Direct Object**: उसे **को** दिया (gave to him)
2. **Possessive**: उसकी किताब (his book)
3. **Locative**: उस**में** (in him)

**MCQ Pattern**:
- Present sentence with missing case marker
- Choose correct case-marked form
- Explain why that marking is used
