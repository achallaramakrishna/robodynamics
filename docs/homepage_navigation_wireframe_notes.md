# Homepage Navigation Wireframe Notes

Date: March 19, 2026

## Goal

Keep the RoboDynamics homepage clean and product-first.

The homepage should not behave like a news portal or a blog.
It should answer one question fast:

`Which product should this parent choose?`

## Homepage Structure

### Top Navigation
- Home
- AptiPath360
- MindSutra
- MindSpark
- MoneyMind
- Contact

Notes:
- show `Live` or `Soon` badge at nav level where needed
- do not expose grade links in the top nav
- do not expose lesson links in the top nav

### Hero
- short positioning statement
- one primary CTA: `Explore Products`
- one secondary CTA: `Start AptiPath360`
- one small panel explaining product-first navigation

### Product Grid
Show only 4 product-family cards:
- AptiPath360
- MindSutra
- MindSpark
- MoneyMind

Each card should contain only:
- product name
- one-line description
- 3-4 chips
- one primary CTA
- optional secondary CTA

Do not show:
- grade cards on the homepage
- chapter lists on the homepage
- news or startup updates on the homepage
- blog/article rail on the homepage

## Navigation Model

### Parent flow
- Home
- Product page
- Grade selection or path selection
- Course detail page
- Demo or purchase
- Course hub
- Tutor mode

### Student flow
- Login
- Course hub
- Resume lesson
- Tutor mode
- Back to course hub

## Product Page Pattern

### MindSutra
- grade tabs or segmented selector for Grade 4-8
- course summary
- curriculum
- demo CTA
- purchase CTA

### MindSpark
- same structure as MindSutra
- same generic engine expectation
- course content changes, UX shell stays the same

### MoneyMind
- same structure later when launched

## Desktop Recommendation
- homepage uses product cards
- product pages use tabs or segmented grade selectors
- course pages show curriculum + CTA + dashboard entry

## Mobile Recommendation
- homepage still uses product cards
- product pages use one grade dropdown instead of many cards
- keep CTA pinned or clearly visible

## Design Principle

The homepage decides the family.
The product page decides the grade.
The course page decides the lesson.
The tutor page teaches.
