## 🚀 How to Execute Generation in Gemini

1. **Copy the [Aesthetic Anchor] prompt** at the top.
2. **Append your target prompt** from the catalog (e.g. for Level 1, Akka: `[Aesthetic Anchor] + "A friendly Indian elder sister..."`).
3. Set the image aspect ratio to **4:3** (Google Gemini/Imagen generates beautiful 800x600px assets natively in this ratio).
4. Save the generated image as a `.png` file using the corresponding **Filename** (e.g., `kaveri_l1_akka_a.png`).
5. Copy and save them directly in the project folder: `apps/kaveri-tutor/public/assets/gemini/`.
