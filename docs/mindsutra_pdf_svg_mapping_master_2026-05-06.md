Date: 2026-05-06
Source PDF: [Manual 1.pdf](C:/Users/Achalla%20Ramakrishna/Downloads/Manual%201.pdf)
Product: MindSutra
Scope: All 40 MindSutra lessons across Levels 1-5

## Purpose

This document maps reusable SVG families from `Manual 1` to the current 40-lesson MindSutra catalog. The goal is to reduce text-heavy explanation and move each lesson toward stronger visual teaching, step sequencing, and lightweight SVG animation.

## Reusable SVG Families From The Manual

These are the highest-value reusable visual families extracted from the PDF:

1. `complement-bar`  
Use for completing to 10, 100, 1000, 10000 and near-base subtraction.

2. `part-whole-number-bond`  
Use for split-and-transfer explanations in addition, subtraction, x5/x25, percentages.

3. `double-half-ladder`  
Use for doubling, halving, factor balancing, and proportional scaling.

4. `base-difference-cross-board`  
Use for near-base multiplication with deficits/surpluses.

5. `vertical-crosswise-band-flow`  
Use for 2-digit, 3-digit, and 4-digit criss-cross multiplication.

6. `moving-multiplier-strip`  
Use for long number x 2-digit multiplication.

7. `duplex-lane`  
Use for general squaring, duplex, and symmetric cross-products.

8. `square-root-inspection-board`  
Use for digit-pair grouping and root selection.

9. `cube-root-inspection-board`  
Use for digit-triple grouping and cube-ending lookup.

10. `division-lane`  
Use for division by 9, division by 99/98, Paravartya, and flag division.

11. `flag-digit-board`  
Use for Dhvajanka and negative flag digits.

12. `bar-number-converter`  
Use for vinculum/bar-number conversion and negative digit normalization.

13. `fraction-cross-board`  
Use for fraction addition, simplification, comparison, and rational number operations.

14. `ratio-balance-board`  
Use for ratio, proportion, and scaling logic.

15. `equation-balance-board`  
Use for one-step, two-step, three-step, and simultaneous equations.

16. `identity-expansion-grid`  
Use for binomials, squares, cubes, and algebraic identities.

17. `power-growth-strip`  
Use for exponent patterns and repeated multiplication structures.

18. `triangle-area-board`  
Use for geometry/triangle area shortcuts.

19. `divisibility-test-board`  
Use for divisibility by 4, 7, 11, 13 and digit checks.

20. `digit-sum-check-board`  
Use for digit sums, casting out nines, validation, and arithmetic checking.
