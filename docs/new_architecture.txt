      1 +# Student Behavior Model
      2 +
      3 +This document defines the learner behaviors the tutor must recognize and accommodate during a live course session.
      4 +
      5 +The current system handles only part of this space. For launch, behavior handling should be explicit rather than accidental.
      6 +
      7 +## Goal
      8 +
      9 +The tutor should not react the same way to every learner.
     10 +
     11 +It must adapt based on:
     12 +
     13 +- speed
     14 +- correctness
     15 +- retries
     16 +- help-seeking
     17 +- confidence
     18 +- skip behavior
     19 +- frustration signals
     20 +
     21 +## Behavior Personas
     22 +
     23 +### 1. Correct Fast
     24 +
     25 +Traits:
     26 +
     27 +- answers correctly on first attempt
     28 +- responds quickly
     29 +- high streak
     30 +
     31 +Tutor response:
     32 +
     33 +- keep explanation short
     34 +- promote faster
     35 +- offer challenge variant
     36 +- reward immediately
     37 +
     38 +### 2. Careful Correct
     39 +
     40 +Traits:
     41 +
     42 +- answers correctly
     43 +- moderate or slow response time
     44 +- low skip behavior
     45 +
     46 +Tutor response:
     47 +
     48 +- keep current pace
     49 +- confirm reasoning
     50 +- move forward without over-explaining
     51 +
     52 +### 3. Hesitant But Teachable
     53 +
     54 +Traits:
     55 +
     56 +- pauses often
     57 +- asks for reassurance
     58 +- succeeds after one hint
     59 +
     60 +Tutor response:
     61 +
     62 +- give one worked cue
     63 +- encourage explicitly
     64 +- ask student to try again quickly
     65 +
     66 +### 4. Wrong But Confident
     67 +
     68 +Traits:
     69 +
     70 +- submits wrong answer quickly
     71 +- confidence signal is high
     72 +- repeats similar mistakes
     73 +
     74 +Tutor response:
     75 +
     76 +- correct misconception directly
     77 +- show one counter-example
     78 +- avoid long encouragement-only replies
     79 +
     80 +### 5. Repeatedly Confused
     81 +
     82 +Traits:
     83 +
     84 +- multiple wrong attempts
     85 +- low mastery trend
     86 +- same subtopic keeps failing
     87 +
     88 +Tutor response:
     89 +
     90 +- reteach simpler
     91 +- break the task into smaller steps
     92 +- move to review loop if needed
     93 +
     94 +### 6. Silent Or Stuck
     95 +
     96 +Traits:
     97 +
     98 +- long no-response gap
     99 +- does not type or speak
    100 +- may reopen help without answering
    101 +
    102 +Tutor response:
    103 +
    104 +- offer a smaller first step
    105 +- ask a simpler question
    106 +- give a starter hint before expecting full answer
    107 +
    108 +### 7. Help-Seeking
    109 +
    110 +Traits:
    111 +
    112 +- asks many doubts
    113 +- wants examples before answering
    114 +- chat-heavy behavior
    115 +
    116 +Tutor response:
    117 +
    118 +- answer briefly
    119 +- return to task quickly
    120 +- avoid turning lesson into open-ended chat
    121 +
    122 +### 8. Guessing Randomly
    123 +
    124 +Traits:
    125 +
    126 +- very fast wrong answers
    127 +- no pattern of reasoning
    128 +- multiple inconsistent guesses
    129 +
    130 +Tutor response:
    131 +
    132 +- slow the learner down
    133 +- require one explicit reasoning step
    134 +- present one worked example
    135 +
    136 +### 9. Frustrated
    137 +
    138 +Traits:
    139 +
    140 +- repeated wrong answers
    141 +- skip tendency increases
    142 +- doubt tone becomes emotional
    143 +- hearts decline quickly
    144 +
    145 +Tutor response:
    146 +
    147 +- shorten the task
    148 +- reduce challenge
    149 +- use supportive phrasing
    150 +- create a quick win
    151 +
    152 +### 10. Advanced Or Bored
    153 +
    154 +Traits:
    155 +
    156 +- fast correct streak
    157 +- very high mastery
    158 +- low need for help
    159 +
    160 +Tutor response:
    161 +
    162 +- compress explanation
    163 +- unlock challenge task
    164 +- reduce repetition
    165 +
    166 +### 11. Skip-Heavy
    167 +
    168 +Traits:
    169 +
    170 +- uses skip often
    171 +- moves through lessons without attempts
    172 +
    173 +Tutor response:
    174 +
    175 +- detect avoidance
    176 +- present a smaller mandatory attempt
    177 +- reduce passive progression
    178 +
    179 +### 12. Example-First Learner
    180 +
    181 +Traits:
    182 +
    183 +- prefers explanation before trying
    184 +- may hesitate if asked to solve immediately
    185 +
    186 +Tutor response:
    187 +
    188 +- show one mini-example
    189 +- then immediately ask for attempt
    190 +
    191 +### 13. Try-First Learner
    192 +
    193 +Traits:
    194 +
    195 +- wants to solve before hearing a full explanation
    196 +
    197 +Tutor response:
    198 +
    199 +- ask student to try first
    200 +- explain only after answer or failure

    243 +
