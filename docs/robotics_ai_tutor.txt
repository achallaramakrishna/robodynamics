The sensor:

Sends a 40 kHz ultrasonic burst (inaudible to humans).
Waves hit object and bounce back.
Measures round-trip time.

Formula (write on screen/whiteboard):
$   \text{Distance (cm)} = \frac{\text{Duration (µs)} \times 0.034}{2}   $
(0.034 = speed of sound in cm/µs; divide by 2 because it's a round trip.)

Phase 4: Coding – Explained Line by Line (15–20 mins)
Tutor shares this basic code, explains each block, then lets student type/modify.
C++Copyconst int trigPin = 9;
const int echoPin = 10;
const int ledPin = 8;   // Change to multiple pins for visual scale

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);   // For seeing distance on screen
}

void loop() {
  // Send trigger pulse
  digitalWrite(trigPin, LOW); delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);           // Measure echo time
  float distance = (duration * 0.034) / 2;          // Calculate cm

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  // LED logic (simple alert)
  if (distance < 15) {
    digitalWrite(ledPin, HIGH);   // Warning!
  } else {
    digitalWrite(ledPin, LOW);
  }

  delay(100);   // Small pause
}
Upgrade for multi-LED "scale": Use if-else or map() to light different LEDs based on distance ranges (e.g., <10 cm = all red LEDs on).
